## Overview

ایرانِ من یک پروژه وب تعاملی برای گشت‌وگذار در نقشه ایران و آشنایی با شهرهای مختلف آن است.

در این پروژه، نقشه تعاملی در کنار تصاویر و اطلاعات شهرها قرار گرفته تا تجربه‌ای ساده و بصری از کشف ایران ایجاد کند.

## Features

- Interactive map of Iran
- City selection and map navigation
- City images and information
- Dark and light mode
- Responsive design
- Persian user interface

## Technologies

- HTML
- CSS
- JavaScript
- MapLibre GL JS
- OpenFreeMap

## Getting Started

Clone the repository:

```bash
git clone https://github.com/ArshamPLUS/iran-e-man.git
```

Open the project directory:

```bash
cd iran-e-man
```

Open `index.html` in your browser or run the project using VS Code Live Server.
